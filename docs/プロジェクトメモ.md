## レスポンシブ対応メモ（部品一覧 SID‑PR‑100）

### レイアウト方針

* **カードレイアウト**で一覧を構築し、Bootstrap の `row-cols-*` を利用してカラム数を自動切替。

  * `row-cols-1` : <576 px（スマホ）では 1 列縦積み
  * `row-cols-md-2` : ≥768 px（タブレット）で 2 列
  * `row-cols-lg-3` : ≥992 px（デスクトップ）で 3 列
* 画像追加時は `card-img-top` を使えば既存構造のまま拡張可能。

### カード構造

```
.card
  ├─ h5.card-title       // 部品名
  ├─ dl.row              // メタ情報
  │   ├─ dt (col-4 / col-sm-3)  // ラベル
  │   └─ dd (col-8 / col-sm-9)  // 内容
  └─ div.d-flex.btn-area // 操作ボタン
```

* `.h-100 + .d-flex` を併用し `.btn-area` に `mt-auto` を付与することで、ボタン群をカード下端に固定。

### メタ情報（作成・更新・オリジナル）

* `<dl>` ラッパーを使用し、ラベルは `fw-bold text-muted` で視認性アップ。
* 列幅はモバイルで 4:8、SM 以上で 3:9 に自動調整。

### 操作ボタン

* 常時横並び：`d-flex flex-row gap-2`（縦並び切替クラスを削除）
* 正方形アイコンボタン `.btn-icon` を共通化

  ```scss
  .btn-icon {
    width: 2.5rem;
    height: 2.5rem;
    padding: 0;
    display: inline-flex;
    align-items: center;
    justify-content: center;
  }
  ```
* ボタン種：詳細（eye）／編集（pencil）／削除（trash）

### スコープ／モデル設定

* 一覧取得：`current_user.parts.alive.includes(:origin_owner).order(updated_at: :desc)`

  * **自分所有のみ** + 論理削除除外 + N+1 回避 + 更新日時降順
* オリジナル作成者は `origin_owner.public_uid` を表示
