# ezdxf チートシート（日本語）

> DXF を **Python** で読み書きするための実用サマリ。
> 例は互換性重視の **R12 + mm（$INSUNITS=4）** 前提です。

---

## 0) インストール

```bash
pip install ezdxf pymupdf  # （PDF/PNG化に PyMuPDF を使う場合）
```

---

## 1) 図面の基本

```python
import ezdxf
from io import StringIO

# 新規作成（互換性重視なら R12、機能を増やすなら R2000 以降）
doc = ezdxf.new("R12", setup=True)      # R12 / R2000 / R2007 ... など
doc.header["$INSUNITS"] = 4             # 4 = mm（単位の明示）
# R12を明示したいとき（通常は new("R12") で十分）
doc.header["$ACADVER"] = "AC1009"       # AC1009 = R12

msp = doc.modelspace()                  # Model Space を取得
```

### DXF 版コードの目安

* `AC1009` = R12
* `AC1015` = R2000
  （R12 は互換性◎、ただし機能は少なめ）

### 単位 `$INSUNITS`

* `0` 未定義, `1` inch, `4` mm, `6` m …
  （mm 運用なら **4** を固定推奨）

---

## 2) レイヤ

```python
doc.layers.new("OUTER", dxfattribs={"color": 1})  # 赤
doc.layers.new("DRILL", dxfattribs={"color": 5})  # 青
doc.layers.new("TEXT",  dxfattribs={"color": 7})  # 白
```

* CAM 連携では **レイヤ名の規約**が重要（例：`OUTER`, `DRILL`）。

---

## 3) エンティティの追加

### 線・円・ポリライン

```python
# 直線
msp.add_line((0, 0), (100, 0), dxfattribs={"layer": "OUTER"})

# 円
msp.add_circle((20, 20), 3, dxfattribs={"layer": "DRILL"})

# 軽量ポリライン（推奨）
pl = msp.add_lwpolyline(
    [(0,0), (100,0), (100,50), (0,50)],
    dxfattribs={"layer": "OUTER"}
)
pl.closed = True  # 閉領域にする
```

> **LWPOLYLINE の円弧**は **bulge** で表現（頂点タプルの5番目）。
> CAM 側の都合で bulge 禁止なら **ARC に展開**して出力を。

### テキスト（位置は `insert`）

```python
msp.add_text("板 100x50", dxfattribs={
    "height": 3.5,             # 文字高さ
    "layer": "TEXT",
    "insert": (0, -10),        # ここが位置（左下基準）
})
```

---

## 4) 寸法（DIMENSION）

```python
# 線形寸法（水平/垂直）
dim = msp.add_linear_dim(
    base=(50, -10),            # 寸法線のベース位置（オフセット）
    p1=(0, 0), p2=(100, 0),    # 寸法の始点・終点
    dimstyle="EZDXF"           # 既定の寸法スタイル
)
dim.render()                    # ← 必須！ ブロック生成して表示可能にする

# 斜め（aligned）の例
# msp.add_aligned_dim(p1=(0,0), p2=(100,50), distance=10).render()
```

* **`render()` を忘れると図面上に見えません**（定番ハマりポイント）。
* 既定のスタイルは `EZDXF`。見栄え調整は DIMSTYLE をカスタム。

---

## 5) 監査（Audit）

```python
aud = doc.audit()
if aud.errors:
    for e in aud.errors:
        print("[AUDIT]", e)
```

* DXF の構造エラーがあればここに集まる。生成直後に回すのがおすすめ。

## 6) 書き出し（ファイル or メモリ）

### ファイルへ保存

```python
doc.saveas("out.dxf")
```

### メモリ（バイト列）で取り出す（Web API など）

```python
buf = StringIO()
doc.write(buf)                  # DXF テキストを出力
dxf_bytes = buf.getvalue().encode("utf-8")  # bytes に
```

> `BytesIO` を使うと `str`/`bytes` でエラーになりがち。**DXFはテキスト**なので `StringIO` → `encode` が安全。

## 8) PDF/PNG への描画（レンダリング）

```python
    # 既存の自作関数を利用してOK（あなたの環境に合わせる）
    ...

def pdf_to_png(pdf_bytes: bytes, width_px=1000) -> bytes:
    pdf = fitz.open(stream=pdf_bytes, filetype="pdf")
    page = pdf[0]
    zoom = width_px / page.rect.width
    mat = fitz.Matrix(zoom, zoom)
    pix = page.get_pixmap(matrix=mat, alpha=False)
    return pix.tobytes("png")
```

## 9) CAM 用 DXF の注意（実務）

* **エンティティ制限**：`LINE / LWPOLYLINE / CIRCLE / ARC` のみに（`TEXT/MTEXT/DIMENSION/HATCH/SPLINE/BLOCK` は原則禁止）
* **閉領域**：外形（OUTER）は閉ポリライン化、0長さ線や重複線を除去
* **単位/版**：`$INSUNITS=4`（mm）明示、慣例的に **R12** が無難
* **bulge**：CAM によっては不可 → `ARC` に展開するポリシーを
* **レイヤ命名**：`OUTER`, `DRILL` など、業者と取り決め
* **監査**：生成後に `doc.audit()` を通し、NGなら返さない

---

## 10) よくあるエラーと対処

* **`'Text' object has no attribute 'set_pos'`**
  → 位置は `entity.dxf.insert = (x, y)` か `add_text(..., dxfattribs={"insert": (...)})`。

* **寸法が見えない**
  → `add_linear_dim(...).render()` を忘れている。

* **`a bytes-like object is required, not 'str'`**
  → `doc.write()` の出力は **テキスト**。`StringIO` で受けてから `encode("utf-8")` する。

* **PDF/PNGで日本語が□になる**
  → コンテナにフォント（`fonts-dejavu-core`,`fonts-noto-cjk` など）を入れる。

## 12) 用語メモ

* **Model Space / Paper Space**：実体を描くのは通常 **Model Space**。
* **Bulge**：LWPOLYLINE 頂点に付く円弧量（`tan(θ/4)`）。禁止なら `ARC` へ分解。
* **DIMSTYLE**：寸法スタイル（文字サイズ、矢印形状など）。

# JISに準拠した三面図

ポイントは「JISの作法（第三角法の配置・線種/線幅・寸法書式・投影法記号）」を**2D要素として自前で組み立てる**ことです。ezdxfは**3D→2Dの自動投影はしない**ので、各視図（正面・平面・側面）の2D輪郭/寸法を与えて配置します。

---

## 何をすればJISライクになるか

* **第三角法の配置**：正面図を基準に、**平面図は上**、**右側面図は右**に配置。
* **線種/線幅**（例）

  * 可視外形：CONTINUOUS / 0.35mm
  * かくれ線：HIDDEN / 0.25mm
  * 中心線：CENTER / 0.25mm
  * 寸法線・補助線：CONTINUOUS / 0.25mm
* **寸法スタイル**：単位mm、文字高・矢印/目盛り形状、基点の丸め等（既存の `override` でOK）。
* **投影法の記号**：表題欄付近に「第三角法」記号（簡易でも可）を置く。
* **表題・尺度**：タイトル、SCALE、材質等の欄。

---

## 実装の最小パターン（1ページ内に三面を並べる）

「ビュー定義」を与えて**オフセット配置**するだけで三面図になります。
（3D→2Dの計算はしません。各視図の輪郭はJSONで与える想定です）

```python
# app/dxf_builder_threeview.py
from typing import Optional, List, Tuple
import ezdxf
from ezdxf.math import Vec2
from ezdxf.entities import Dimension
from .dxf_builder import _new_doc_mm, _add_dimensions  # 既存を再利用

Point = Tuple[float, float]

class ViewData:
    def __init__(self, name:str, origin:Point,
                 polylines:list, circles:list, dimensions:list):
        self.name = name
        self.origin = origin
        self.polylines = polylines
        self.circles = circles
        self.dimensions = dimensions

def _add_primitives_at(msp, polylines, circles, origin:Point):
    ox, oy = origin
    for pl in polylines or []:
        pts = [(x+ox, y+oy) for (x, y) in pl.points]
        lw = msp.add_lwpolyline(
            pts, format="xy", close=pl.closed,
            dxfattribs={"layer": pl.layer}
        )
        lw.closed = pl.closed
    for c in circles or []:
        cx, cy = c.center
        msp.add_circle((cx+ox, cy+oy), c.r, dxfattribs={"layer": c.layer})

def _add_view_label(msp, name:str, origin:Point, width:float):
    # ビュー名を上中央に
    style = "CJK" if "CJK" in msp.doc.styles else "Standard"
    txt = msp.add_text(name, dxfattribs={"height": 4, "layer": "TEXT", "style": style})
    txt.dxf.halign = 1  # center
    txt.dxf.valign = 3  # top
    txt.dxf.align_point = (origin[0] + width/2.0, origin[1] - 6)

def _add_projection_symbol(msp, base:Point=(10, -25)):
    # 簡易な第三角法記号（プレースホルダ）
    x, y = base
    msp.add_circle((x+6, y+6), 6, dxfattribs={"layer":"CENTER"})
    msp.add_circle((x+6, y+6), 3.5, dxfattribs={"layer":"CENTER"})
    msp.add_line((x+18, y), (x+32, y), dxfattribs={"layer":"CENTER"})
    msp.add_line((x+18, y+12), (x+32, y+12), dxfattribs={"layer":"CENTER"})
    # 必要なら専用BLOCKに差し替えてください

def _set_jis_layers(doc: ezdxf.EzDxf):
    # 線種はsetup=Trueで基本は入るが、明示でOK
    lts = doc.linetypes
    for name in ("HIDDEN", "CENTER"):
        if name not in lts:
            lts.add(name)  # 既定パターンを追加

    def add_layer(name, color, ltype="CONTINUOUS", lw=25):
        if name not in doc.layers:
            doc.layers.add(name, dxfattribs={"color": color, "linetype": ltype, "lineweight": lw})

    add_layer("OUTER", 7,  "CONTINUOUS", 35)
    add_layer("HIDDEN",8,  "HIDDEN",     25)
    add_layer("CENTER",5,  "CENTER",     25)
    add_layer("DRILL", 1,  "CONTINUOUS", 25)
    add_layer("TEXT",  7,  "CONTINUOUS", 25)
    add_layer("DIM",   2,  "CONTINUOUS", 25)

def build_three_views_dxf(payload, views: List[ViewData], view_sizes:dict):
    """
    views: ViewData の配列（正面・平面・右側面）
    view_sizes: {"正面図":(W,H), "平面図":(W,H), "右側面図":(W,H)} などラベルの外寸（ラベル配置用）
    """
    doc = _new_doc_mm()
    _set_jis_layers(doc)
    msp = doc.modelspace()

    # 各ビューの形状
    for v in views:
        _add_primitives_at(msp, v.polylines, v.circles, v.origin)
        # 寸法：既存関数を使い、原点平行移動だけ反映
        class P: pass
        p = P(); p.dimensions = []
        for d in v.dimensions or []:
            # p1,p2,base だけオフセット（aligned/linear両対応）
            dd = d.model_dump()  # pydantic → dict
            def off(pt): return (pt[0]+v.origin[0], pt[1]+v.origin[1]) if pt else None
            dd["p1"] = off(dd.get("p1"))
            dd["p2"] = off(dd.get("p2"))
            if "base" in dd: dd["base"] = off(dd.get("base"))
            p.dimensions.append(payload.Dimension(**dd))
        _add_dimensions(msp, p)

        # ビュー名ラベル
        w, _h = view_sizes.get(v.name, (0.0, 0.0))
        _add_view_label(msp, v.name, v.origin, w)

    # 投影法記号
    _add_projection_symbol(msp)

    # タイトル（右下など、お好みの位置へ）
    if payload.title:
        style = "CJK" if "CJK" in doc.styles else "Standard"
        t = msp.add_text(payload.title, dxfattribs={"height":5, "layer":"TEXT", "style":style})
        t.dxf.insert = (200, -25)

    return doc
```

> 使い方：各視図の2D形状/寸法をあなたのJSONから作って `ViewData` に渡し、
> 原点（`origin`）で配置を決めれば、**1ページ内の三面図**ができます。
> 線種・線幅・フォント・DIMはあなたの既存設定と整合させています。

---

### JSONの持ち方（例）

三面を**ページではなくビュー**として1ページ内に並べる想定（例）：

```jsonc
{
  "title": "部材A",
  "views": [
    { "name": "正面図", "origin": [0, 0],
      "polylines": [ /* 正面の輪郭... */ ],
      "circles":   [ /* 正面で見える穴... */ ],
      "dimensions":[ /* 正面の寸法... */ ] },
    { "name": "平面図", "origin": [0, 90],
      "polylines": [ /* 平面の輪郭... */ ],
      "circles":   [ /* 平面の穴... */ ],
      "dimensions":[ /* 平面の寸法... */ ] },
    { "name": "右側面図", "origin": [150, 0],
      "polylines": [ /* 右側面の輪郭... */ ],
      "circles":   [],
      "dimensions":[ /* 側面の寸法... */ ] }
  ]
}
```

> ※原点オフセット（`origin`）を調整すればJISの配置（上＝平面、右＝右側面）に。
> **かくれ線や中心線**は、該当エッジを `layer:"HIDDEN"` / `layer:"CENTER"` で与えればOK（線種と線幅はレイヤ定義で反映）。

### よくある質問

* **3Dから自動で三面図を作れる？**
  いいえ。ezdxfは**製図の容れ物**で、3D→2Dの可視化・隠線消去はやりません。必要なら OpenCascade など別エンジンで投影し、**結果の2Dをezdxfに流し込む**方針です。
* **投影法の正式記号は？**
  ここでは簡易記号を描いています。正式なブロックをDXFで用意して `doc.blocks.new()`→`msp.add_blockref()` で挿入するのが綺麗です。
* **線幅の単位**
  DXFの `lineweight` は 1/100 mm 単位（例：25=0.25mm）。例のレイヤ設定はそれに合わせています。

この2点（①対象業種の事業所数が多い、②機械の価格が高い）を踏まえると、**木材関連の事業所“全体”で見たときは、非保有が多数派**と見るのが現実的です。逆に、**対象を「看板・内装・店舗什器・造作家具などで2D曲線カットを常用する中規模以上」へ絞ると、保有（自社 or 提携先）がかなり増える**、というのが実務感覚に近いところです（ただし比率の正確な数値は公開されていません）。

### 実務に落とすなら

比率そのものより、マッチング時に以下の“能力タグ”で切る方が有効です。

* **設備**：CNCルータ（有/無）、テーブル有効寸法、最小ビット径/刃長、真空テーブルの有無
* **対応素材**：合板/MDF/集成材/樹脂/アルミ複合板 など
* **精度と面品質**：面粗さ・許容差・バリ/毛羽の後処理可否
* **入稿**：DXF（mm/レイヤ規約）可、曲線（NURBS/スプライン）可、PDF仕様読解可

こうして“CNC あり系”と“直線専用（パネルソー・ビームソー・バンドソー中心）”を最初から分けて募集すれば、実務上は比率を気にせずに最適化できます。
